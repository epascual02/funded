CARPETA PARA CERTIFICADOS DE RETIROS

Subí aquí las imágenes o PDFs que quieras utilizar como evidencia de retiros.
Antes de publicar, ocultá datos personales, números de cuenta, IDs, correos,
direcciones y cualquier información privada o credencial.

IMPORTANTE:
- Esta carpeta es pública al desplegar el sitio en Vercel.
- Todo archivo colocado aquí podrá ser accesible mediante una URL pública.
- No subas documentos originales que contengan información sensible.
- Los archivos no se muestran automáticamente en la web todavía; primero
  revisaremos cuáles querés publicar y luego incorporaremos una galería.
